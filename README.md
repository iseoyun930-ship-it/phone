# ST Phone — 폰·SNS 시뮬레이터 (SillyTavern 확장)

화면에 떠 있는 📱 버블을 누르면 폰이 열리고, 캐릭터와 문자를 주고받고 SNS 피드를 볼 수 있는 실리태번 확장이에요.
코드가 앱 구조·저장·정보 차단을 맡고, AI는 **내용(문자·게시글·댓글)만** 만들어요.

## 기능

- **📱 플로팅 버블**: 눌러서 폰 열기 / 끌어서 위치 이동 (모바일 대응)
- **💬 메시지**: 캐릭터별 대화방, 입력 중 표시, 먼저 연락 오게 하기, 자동 답장
- **📸 피드**: AI 게시글 새로고침, 글쓰기, 좋아요, 댓글, AI 반응 생성
- **👥 프로필**: 누가 누구를 팔로우하는지 설정
- **⚙️ 설정**: 폰 시간 조절, 메인 채팅 연동, 언어, 포인트 색
- **정보 차단**: 캐릭터는 자신이 보내거나 올린 것, 팔로우한 계정의 글만 알아요
- **채팅별 저장**: RP마다 폰 데이터가 따로 저장돼요
- **🤖 자동 모드**: 메인 채팅이 진행되면 캐릭터가 알아서 글을 올리고, 먼저 문자를 보내고, 댓글을 달아요 (기본 꺼짐)
- **메인 채팅 연동**: 최근 폰 활동이 메인 채팅 프롬프트에 자동으로 들어가요 (끌 수 있음)

## 설치

1. 실리태번 → 상단 **Extensions(퍼즐 아이콘)** → **Install extension**
2. 아래 주소를 붙여 넣고 설치
   `https://github.com/내아이디/st-phone`
3. 페이지를 새로고침하면 화면에 📱 버블이 나타나요.

## GitHub에 올리는 방법 (웹에서)

1. github.com → **New repository** → 이름 `st-phone`, **Public**으로 생성
2. **Add file → Upload files**에서 `manifest.json`, `index.js`, `style.css`, `README.md` 4개를 올리기
   (폴더째 말고 **저장소 맨 위(루트)** 에 파일이 있어야 해요)
3. **Commit changes**
4. `manifest.json`의 `author`, `homePage`의 `YOUR_NAME`, `YOUR_GITHUB_ID`를 내 정보로 바꾸기

수정 후에는 같은 방법으로 파일을 다시 올리고, 실리태번 Extensions에서 업데이트하면 돼요.

## 사용 팁

- 먼저 **캐릭터 채팅**을 열어야 폰이 동작해요. (채팅이 없으면 폰이 비어 있어요)
- 피드의 **새로고침**을 누르면 캐릭터들이 올린 글이 생겨요.
- AI 응답은 JSON으로 받아요. 가끔 해석에 실패하면 "다시 시도"를 눌러 주세요.
- 설정에서 **폰 활동을 메인 채팅에 반영**을 끄면 메인 채팅은 폰 내용을 몰라요.

## 자동 모드

폰 ⚙️ 설정 → **자동 모드**에서 켜요. (기본은 꺼져 있어요)

- **캐릭터 메시지 N개마다 실행**: 기본 4개마다 AI 호출 1번
- **메시지 1개당 폰 시간(분)**: 메인 채팅이 진행될수록 폰 시간도 같이 흘러요 (0이면 안 흘러감)
- **지금 한 번 실행**: 바로 테스트해 볼 수 있어요
- 새 활동이 생기면 알림이 뜨고, 안 읽은 문자는 📱 버블에 숫자로 표시돼요.
- 캐릭터는 자기가 아는 것(자기 활동, 팔로우한 계정, 메인 채팅)만 바탕으로 활동해요.

## 요구 사항

- SillyTavern 1.12 이상 (`generateQuietPrompt`, `setExtensionPrompt`, `chatMetadata` 사용)
